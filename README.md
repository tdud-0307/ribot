# AI 기반 인체 맞춤형 웨어러블 로봇팔

## 실행
ZIP의 파일을 GitHub 저장소 루트에 업로드하고 Streamlit Cloud의 메인 파일을 `main.py`로 지정하세요.

## 사용 방법
1. 로봇팔 유형을 선택합니다.
2. 팔 전체와 기준자가 함께 나온 JPG/PNG 사진을 업로드합니다.
3. 사이드바에 기준자의 실제 길이(cm)와 사진 속 픽셀 길이(px)를 입력합니다.
4. AI가 팔 관절을 인식하고 기준 길이 비율로 상완·하완 길이를 추정해 3D 로봇팔 시뮬레이션에 반영합니다.

## 기준 길이 보정
cm/px = 기준자의 실제 길이(cm) ÷ 사진 속 기준자의 픽셀 길이(px). 예: 실제 30cm 자가 사진에서 300px이면 0.1cm/px입니다.

**주의:** 기준자의 픽셀 길이는 이미지에서 직접 측정해 입력해야 합니다. 자와 팔은 같은 평면/거리에 있어야 원근 오차가 줄어듭니다. 단일 사진의 2D 관절 인식은 추정치이며 실제 의료·보조기기 제작 치수로 사용하면 안 됩니다.
